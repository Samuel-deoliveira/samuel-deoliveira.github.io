# Variable public

:::tip INFO
La variable est **<span style="color: #8067aa">accessible depuis n'importe quelle classe</span>**, indépendamment de leurs paquets ou de leurs relations d'héritage.
:::

**<span style="color: #8067aa">Exemple</span>**:

::: code-group
```java [Exemple.java]
public class Exemple {
  public int variablePublic;
}
```
:::

:::warning
Dans cette exemple, `variablePublic` sera accessible depuis n'importe quelle classe.
:::
