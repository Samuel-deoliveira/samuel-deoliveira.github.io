# Type de données de référence

:::tip INFO
Les types de données référence **<span style="color: #8067aa">représentent des objets</span>**, y compris les **<span style="color: #8067aa">classes personnalisées</span>**, les **<span style="color: #8067aa">tableaux</span>** et les **<span style="color: #8067aa">chaines de caractères</span>** (String).
:::

Exemple:

* `String`
* `Object`
* `MonObject`
