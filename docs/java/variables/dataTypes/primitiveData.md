# Type de données primitifs

:::tip INFO
Les types de données primitifs sont **<span style="color: #8067aa">les types de base</span>** du langage Java.
:::

**<span style="color: #8067aa">Tels que:</span>**

* `byte` (8 bit, -128 à 127)
* `short` (16 bits, -32 768 à 32 767)
* `int` (nombre à virgule flottant simple précision, 32 bits)
* `double` (nombre à virgule flottant double précision, 64 bits)
* `char` (caractères Unicode, 16 bits)
* `boolean` (vrai ou faux)
