# Variable locale

:::tip INFO
Les variables **<span style="color: #8067aa">déclarées à l'intérieur</span>** d'**<span style="color: #8067aa">une méthode</span>** ou d'**<span style="color: #8067aa">un bloc de code</span>** sont appelées variables locales. Elles sont **<span style="color: #8067aa">accessibles</span>** qu'**<span style="color: #8067aa">à l'intérieur</span>** de **<span style="color: #8067aa">cette méthode</span>** ou de **<span style="color: #8067aa">ce bloc de code</span>**.
:::
