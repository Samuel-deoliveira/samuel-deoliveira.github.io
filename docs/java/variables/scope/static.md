# Variable statique

:::tip INFO
LEs variables déclarées à **<span style="color: #8067aa">l'intérieur d'une classe</span>** avec le mot-clé `static` sont **<span style="color: #8067aa">appelées variables statiques</span>**. Elles sont **<span style="color: #8067aa">accessibles</span>** à partir de **<span style="color: #8067aa">n'importe quelle méthode statique de la classe</span>**.
:::
