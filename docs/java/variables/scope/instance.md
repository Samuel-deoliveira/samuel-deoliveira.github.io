# Variable d'instance

:::tip INFO
Les variables déclarées à **<span style="color: #8067aa">l'intérieur d'un classe</span>** mais en **<span style="color: #8067aa">dehors de toute méthode</span>**, sont appelées **<span style="color: #8067aa">variables d'instance</span>**. Elles sont **<span style="color: #8067aa">accessibles</span>** à partir de **<span style="color: #8067aa">n'importe quelle méthode non statique de la classe</span>**.
:::
