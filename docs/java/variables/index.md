# Les variables

:::tip INFO
Les variables sont des **<span style="color: #8067aa">éléments fondamentaux de la programmation</span>**, utilisées pour stocker des données dans la mémoire de l'ordinateur. En Java, **<span style="color: #8067aa">chaque variable a un type de données</span>** spécifique qui **<span style="color: #8067aa">détermine le genre de valeurs</span>** qu'elle peut contenir et **<span style="color: #8067aa">les opérations qui peuvent être effectuées sur elle</span>**. Voici quelques points clés sur les variables en Java.
:::
