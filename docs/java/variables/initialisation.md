# Initialisation de variables

:::tip INFO
Après avoir déclaré une variable, vous pouvez lui attribuer une valeur. L'opération d'affectation "**<span style="color: #8067aa">=</span>**" est utilisé pour cela.
:::

**<span style="color: #8067aa">Exemple</span>**:

```java
age = 50;
nom = "Alice"
```

:::tip INFO
Vous pouvez également déclarer et initialiser une variable en une seule ligne.
:::

Exemple:

```java
int age = 25;
String nom = "Alice";
```
