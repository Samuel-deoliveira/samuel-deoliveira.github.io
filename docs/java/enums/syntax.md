# Syntaxe

:::tip INFO
Les énumérations sont définies à l'aide du mot-clé enum, suivi du nom de l'énumération et d'une liste de constantes entre accolades. Les constantes sont généralement représentées par des identifiants en majuscules.
:::

Exemple:

:::code-group
```java [Couleur.java]
public enum Couleur {
  ROUGE,
  VERT,
  BLEU
}
```
:::
