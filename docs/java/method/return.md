# Type de retour

:::tip INFO
Le type de retour d'une méthode indique le type de valeur que la méthode renvoie. Si une méthode ne renvoie aucune valeur, le type de retour est void.
:::

Exemple:

```java
public void afficherResultat(int a, int b, int resultat) {
  System.out.println("Le résultat de " a + " * " + b + " est : " + resultat);
}
```
