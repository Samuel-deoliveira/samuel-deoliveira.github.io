# Déclaration de méthode

Une méthode est déclarée en précisant d'abord le modificateur d'accès, puis le type de retour, suivi du nom de la méthode et de la liste des paramètres entre parenthèses. Enfin, le corps de la méthode est défini entre accolades.

Exemple:

```java
public int additionner(int a, int b) {
  int somme = a + b;
  return somme;
}
```
